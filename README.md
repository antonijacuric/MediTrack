## Was ist Git?

Git ist ein verteiltes Versionskontrollsystem, das Änderungen an Dateien dokumentiert und die gemeinsame Entwicklung von Software ermöglicht.

### Warum wird Git verwendet?

- Änderungen an Dateien können nachvollzogen werden.
- Mehrere Personen können gleichzeitig an einem Projekt arbeiten.
- Frühere Versionen lassen sich wiederherstellen.
- Branches ermöglichen die Entwicklung neuer Funktionen, ohne den Hauptstand direkt zu verändern.
- Über GitHub können Änderungen gemeinsam überprüft und zusammengeführt werden.
